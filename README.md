# 🚀 Portfólio de Física e Geometria com Python (Portfólio STEM Completo) + Jogo do Foguete

Bem-vindo ao meu laboratório de simulações! Aqui reuni 8 projetos explorando física vetorial, renderização 3D e interatividade web. Sendo um portfólio STEM (Ciência, Tecnologia, Engenharia e Matemática) completo e muito útil para atividades acadêmicas ou para quem tem curiosidade em aprender Mecânica Clássica e Álgebra Linear a fundo.

## 🌟 Destaque: Falcon Lander Simulator
Um simulador de pouso de foguete estilo SpaceX com física realista e inspirado no jogo retrô dos anos 80 como Asteroids.

🔧 O que foi implementado "na unha" (Sem Engines Prontas):

• Física Vetorial: Cálculos de gravidade, empuxo e inércia aplicados a corpos rígidos.

• Sistema de Colisão: Detecção precisa para diferenciar um pouso suave de uma explosão catastrófica.

• Renderização 3D: Projeção de sólidos geométricos usando matrizes de rotação puras.

• Integração Web: Visualizador geométrico interativo exportado para o navegador.

É incrível ver como conceitos de Cálculo e Física ganham vida quando aplicados com Python. O projeto conta com  via código!

## 🛠️ Tecnologias Usadas
* **Python 3.12**
* **Pygame** (Motor de Física e Gráficos)
* **Math** (Álgebra Linear, Vetores, Matrizes de Rotação)
* **HTML/JS** (Visualização Web em Python)
* **Matplotlib** (Bibliotecas matemáticas)
* **Numpy** (Operações matemáticas)

## 📂 Estruturas dos Projetos
1.  **Falcon Lander:** Jogo de pouso com gravidade e colisão.
2.  **Geometric Web:** Visualizador 3D exportado para o navegador.
3.  **Simulações:** Fluidos (SPH) e Tecidos.
4.  **Matemática:** Renderização de sólidos 3D "na unha" (sem engine pronta).

## 🎮 Como Rodar os Simuladores
1.  Tenha o Visual Studio Code (recomendado) instalado, depois instale o Python (A versão tem que ser 3.12 ou atual) e as bibliotecas tem que ser instaladas via Terminal do VsCode como: Numpy, Matplotlib, Plotly e o mais importante pra rodar o jogo o Pygame -> Ex: `pip install pygame`
2.  Baixe este repositório.
3.  Com o VSCode aberto, abra o arquivo desta pasta do repositório e divirta-se com os simuladores clicando apenas em ▶︎ executar o código. Para o jogo do foguete, execute o arquivo do foguete: `python Game_Rocket_Simulator/o_jogo_de_simulador_de_foguete.py` ou simplesmente abra este arquivo e execute manualmente.
